SHARE Requirement SOCMSX93003

This distribution of the CMS Pipelines runtime library was made available in response to SHARE requirement SOCMSX93003, which requested IBM's permission for software vendors (including shareware vendors) to package a current version of the CMS Pipelines runtime library with their software products in order that they could use new features of Pipes in their products.

Support

There is no formal support for the code and documentation included in this distribution. If you experience a problem with the code or documentation, please report it on one of the Pipelines fora:
  • PROB PIPELINE on VMSHARE
  • PIPELINE CFORUM on IBMLink
  • CMSPIP-L LISTSERV list

Or send email directly to the author, John Hartmann, at jphartmann@vnet.ibm.com.
